# EASTER Paper

Working manuscript for the EASTER/DRC paper — the credibility calling card for
the EASTER project and Witsbi Inc.

## Working title (undecided)

Candidates:

1. **EASTER: A Governed-State Kernel for AI Runtimes** — straight descriptive.
2. **EASTER: Coordination Without Credentials** — the kernel principle as the hook.
3. **The Honest Substrate: EASTER and the Case for Governed Agent State** — frames the paper as an argument.

The manuscript covers **both EASTER and DRC** (Distinction, Relation, Constraint).
The MATH/MoI material is slated for a separate later paper.

## Status

Early drafting. Nothing here is submission-ready; structure and claims are still
being worked out.

- `paper/draft2/` — the manuscript itself (section files; assembled only for review copies).
