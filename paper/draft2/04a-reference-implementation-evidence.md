## 4.10 Reference-implementation evidence boundary

The implementation claims in this section are grounded in the EASTER reference-kernel repository and archived adversarial-review material [1][2]. The publication archive does not yet pin an immutable release/tag for every implementation claim; that reproducibility step remains explicitly pending rather than being inferred from the manuscript. Final submission should replace the provisional repository-level citation with the exact public kernel commit or release used for the reported implementation state.
